## ⚡ Overview

This repository hosts the source code for **Swayam Jha's personal engineering portfolio**. Built from the ground up with clean, dependency-free vanilla web technologies (HTML5, semantic CSS, modular modern JavaScript), the site delivers sub-50ms load times, high-fidelity responsive layout systems, and smooth GPU-accelerated micro-interactions.

### Core Sections:
- **Hero & Philosophy**: Crisp statement of engineering ethos — "Breaking systems deeply to build unbreakable backends."
- **Featured Projects Grid**: Interactive project cards showcasing **Predicta**, **SENTINEL-SCAN**, **APRE**, **StitchIT**, and **CameraCanvas** with live demo links and technical summaries.
- **Skills Matrix**: Categorized breakdown of backend architectures, databases, cloud runtimes, and security tooling.
- **Interactive Terminal / Contact**: Frictionless connection points via GitHub, LinkedIn, and email.

## 🎨 Design System & Aesthetics

- **Color Palette**: 
  - Background: Deep Obsidian (`#0B0F17`)
  - Surface: Midnight Slate (`#121826`)
  - Accent / Primary: Cyber Teal (`#00F5D4`)
  - Secondary: Electric Indigo (`#6366F1`)
  - Text: Frost White (`#F8FAFC`) and Muted Gray (`#94A3B8`)
- **Typography**: Clean monospace headings paired with modern sans-serif body typography.
- **Motion**: Intersection-Observer powered staggered scroll reveals with graceful fallbacks.

## 🚀 Local Development

To run or preview the portfolio locally:

```bash
# Clone the repository
git clone https://github.com/Swayam-jhaa/Portfolio.git
cd Portfolio

# Launch with any local HTTP server:
# Using Python:
python -m http.server 3000

# Or using Node:
npx serve .
```

Open `http://localhost:3000` in any modern web browser.
