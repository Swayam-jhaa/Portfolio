# Technical Stack & Core Competencies

Comprehensive matrix of languages, backend technologies, AI frameworks, infrastructure tools, and security competencies.

---

## 🛠️ Technology Classification

### 1. Languages
- **Python**: Primary language for high-performance backends, asynchronous microservices, data processing pipelines, AI systems, and security tooling.
- **TypeScript**: Modern enterprise frontend and full-stack development (Next.js 14/15, React 19, strict type contracts, typed API layers).
- **JavaScript (ES6+)**: Vanilla DOM manipulation, Web APIs, high-performance animation sequencing, Node.js runtimes.
- **C++**: Low-level systems programming, memory safety principles, algorithms, and computational performance.
- **Bash / POSIX Shell**: Scripting, OS-level automation, CI/CD runners, Docker container entrypoints, and environment provisioning.
- **SQL**: Complex relational queries, schema migrations, indexing optimization, CTEs, and transaction isolation.

---

### 2. Backend & Systems Architecture
- **Frameworks & Runtimes**: FastAPI, Node.js, Express, Next.js Server Components / Route Handlers, Streamlit.
- **Asynchronous & Concurrency Patterns**: `asyncio`, Producer-Consumer Queues, ThreadPool / ProcessPool executors, WebSockets, SSE (Server-Sent Events).
- **Task Queues & Background Workers**: Celery, Redis Streams, asynchronous job schedulers, resilient retry loops with exponential backoff.
- **Databases & Data Storage**:
  - **Relational**: PostgreSQL, MySQL, Supabase, SQLite.
  - **In-Memory & Cache**: Redis (caching, distributed pub/sub, rate limiting, session storage).
  - **Document**: MongoDB.
  - **ORM & Data Modeling**: SQLAlchemy, Prisma ORM, Alembic migrations, Pydantic data validation.
- **API Design**: RESTful API design, OpenAPI / Swagger specifications, webhook ingestion systems, rate limiting, and defensive payload validation.

---

### 3. AI Engineering & Intelligent Systems
- **Retrieval-Augmented Generation (RAG)**: Chunking strategies, semantic embedding generation, vector similarity search, reciprocal rank fusion (RRF), cross-encoder reranking.
- **Vector Stores & Embeddings**: High-dimensional vector indexing, similarity metrics (cosine distance, dot product), metadata filtering.
- **LLM Orchestration & Evaluation**: Multi-model routing (Gemini, OpenAI, Claude), prompt engineering, structured JSON outputs, hallucination minimization, and benchmark evaluations.
- **Autonomous Multi-Agent Systems**: Agent role decomposition, hierarchical task orchestration, stateful execution graphs, automated verification loops (demonstrated in *APRE* and *TechPulse*).
- **Computer Vision & Media Intelligence**: Real-time hand-landmark tracking, MediaPipe, HTML5 Canvas manipulation, frame extraction.

---

### 4. Infrastructure, DevOps & Cloud
- **Containers & Virtualization**: Docker, Docker Compose, multi-stage minimal build optimization, container isolation.
- **Linux & OS Internals**: Debian/Ubuntu, Kali Linux, process monitoring, IPC, systemd services, permission modeling, networking namespaces.
- **Cloud & Deployment**: Vercel (Production Next.js deployments), GitHub Actions CI/CD automation, environment secret management.
- **Observability**: Structured JSON logging, health checks, error boundaries, performance metric collection.

---

### 5. Security & Offensive Engineering (Architectural Moat)
- **Attack Surface Management (ASM)**: Network reconnaissance automation, banner grabbing, port discovery, sub-domain mapping, service fingerprinting.
- **Application Security (AppSec)**: OWASP Top 10 mitigation (SQLi, XSS, CSRF, IDOR, SSRF, Broken Auth, Broken Object-Level Authorization).
- **Security Assessment Tooling**: Burp Suite Professional, Nmap, Wireshark, Metasploit, Nikto, SQLMap.
- **Secure System Design**: Principle of Least Privilege (PoLC), zero-trust boundary verification, HMAC signed webhooks, cryptographic entropy analysis, and token lifecycle management.
- **Hands-on Platforms**: TryHackMe, PortSwigger Web Security Academy.
